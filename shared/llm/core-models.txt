# fox-llm-update downloads them — on first install (fox-install's models step queues it), then from its daily
# timer — into ~/.local/share/fox-llm/gguf/<name>.gguf, where fox-llm-serve serves each under <name>. Blocks
# are picked by system RAM:
#   tier: large   ≥ 32 GB   tier: medium  ≥ 16 GB   tier: small   < 16 GB
#   tier: all     every machine (small helpers other tools depend on)
# Each line: name  user/repo/file.gguf. Every file passed llama.cpp's loader on its real header before it went
# in (sparse skeleton through llama-fit-params, 2026-10-14). Personal / abliterated picks: your own list,
# ~/code/custom_models/gguf-models.conf (same format), not here.
#
